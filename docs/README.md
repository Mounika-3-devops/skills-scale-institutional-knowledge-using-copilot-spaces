# OctoAcme Project Management Docs

This directory is the landing page for OctoAcme's project management knowledge base. It provides a quick overview of how OctoAcme approaches projects from idea to delivery, and links to the detailed process documents used across the organization.

## Project management approach

OctoAcme follows a simple, customer-focused lifecycle:

1. Initiation — validate the problem, align stakeholders, and confirm the business value.
2. Planning — define scope, milestones, dependencies, and an actionable backlog.
3. Execution and tracking — deliver work through sprint or iteration rhythms, track progress, and manage blockers.
4. Release and deployment — verify readiness, ship changes safely, and communicate impact.
5. Retrospective and continuous improvement — capture learnings and improve the delivery process over time.

## Core roles

- Project Managers coordinate delivery, schedules, risks, and cross-team communication.
- Product Managers define outcomes, priorities, and success criteria.
- Developers build, test, and maintain the product.
- QA and testing teams validate quality and acceptance before release.
- Stakeholders provide input, approval, and business context.
